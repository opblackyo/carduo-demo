# CarDuo demo

Three interactive vehicle-shopping prototypes. Start at https://opblackyo.github.io/carduo-demo/

- Atelier: apps/ateliers/
- Market: apps/market/
- Match: apps/match/

Bookings, accounts and payments are simulated in browser localStorage. No live transactions or shared database.
